Experiment 1: GitHub Repository and GitHub Pages

Set up a repository, create branches, merge changes and host a static website.

← Back to all experiments

Aim

To create and manage a GitHub repository, understand branches, commits and merges, and publish a static website using GitHub Pages.

Steps Performed

  1. Create a repository named web-designing-lab on GitHub.
  2. Add project files and commit them to the main branch.
  3. Create a branch named experiment-1.
  4. Make a change on the branch and commit it.
  5. Merge the branch into main using a pull request.
  6. Open Settings → Pages, choose main and /(root), then save.
  7. Open the published GitHub Pages URL to test the website.

Basic Git Commands

git init – initializes a Git repository.

git add . – stages project files.

git commit -m "First commit" – saves a snapshot.

git branch experiment-1 – creates a branch.

git switch experiment-1 – switches branches.

git merge experiment-1 – merges a branch into the current branch.

git push – uploads commits to GitHub.

Result

A GitHub repository manages project versions and GitHub Pages hosts the static website.
